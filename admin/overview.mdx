## Overview

The Admin API is a set of endpoints on the Gennoctua backend for managing brands. It is protected by an admin secret and should **never be exposed publicly**.

**Base URL:** `https://api.gennoctua.com`

**Authentication:** All admin endpoints require the `x-admin-secret` header.

```bash
curl https://api.gennoctua.com/admin/brands \
  -H "x-admin-secret: YOUR_ADMIN_SECRET"
```

<Warning>
Keep your admin secret private. Never expose it in frontend code, public scripts, or git repositories.
</Warning>

---

## What You Can Do

| Action | Endpoint |
|---|---|
| List all brands | `GET /admin/brands` |
| Add a new brand | `POST /admin/brands` |
| Deactivate a brand | `DELETE /admin/brands/:brandKey` |

---

## Authentication

All endpoints require:

```
x-admin-secret: YOUR_ADMIN_SECRET
```

The admin secret is set in the `.env` file on the Gennoctua backend server (`ADMIN_SECRET`).

If the header is missing or incorrect, you'll get:

```json
{ "error": "Unauthorized" }
```

---

## Error Responses

| Status | Body | Meaning |
|---|---|---|
| `401` | `{ "error": "Unauthorized" }` | Wrong or missing admin secret |
| `400` | `{ "error": "..." }` | Missing required fields |
| `409` | `{ "error": "Brand key already exists" }` | Duplicate brand key |
